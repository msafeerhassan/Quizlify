## Coded in Python

A simply Quiz Game Coded in Python

### Features

1. Leaderboards
2. Scoring
3. Timer
4. AI-based Questions Generation
5. Document-based Questions
6. Well-organised Code
7. Efficient Input Error Handling

### How to test it?

Simply, run .exe (execution) file for running the game. If it fails, try using Command Prompt to open the .exe file.
